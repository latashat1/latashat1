## 📂 Featured Portfolio: [databricks-portfolio](https://github.com/latashat1/databricks-portfolio)

Three end-to-end data engineering projects, each demonstrating a different orchestration approach and a different real-world domain:

### 🏥 [Healthcare Claims & Utilization](https://github.com/latashat1/databricks-portfolio/tree/main/01_healthcare_claims_util)
Medallion architecture (bronze/silver/gold) on Medicare-style claims data, a provider fraud-risk ML feature table, Databricks Workflows orchestration, a Lakeflow Declarative Pipeline, and a Genie-powered natural language query space.

### 🏠 [Property & Casualty Underwriting & Claims](https://github.com/latashat1/databricks-portfolio/tree/main/02_pc_underwriting_claims)
Real government open data (Wisconsin property insurance fund) built entirely on **Lakeflow Declarative Pipelines** as the primary orchestration method, with AI-assisted dashboard authoring and a fully governed DABs deployment.

### 🚗 [Auto Insurance Claims & Telematics](https://github.com/latashat1/databricks-portfolio/tree/main/03_auto_insurance_telematics)
The most technically diverse project: **real-time streaming with Apache Kafka** (Confluent Cloud) alongside batch claims ingestion, **PostgreSQL Lakehouse Federation** for live cross-platform data (via Neon — now a Databricks-owned product), and a multi-source DABs-deployed Job with parallel task execution.

### 🛍️ [Retail Analytics & Product Dimension History](https://github.com/latashat1/databricks-portfolio/tree/main/04_retail_analytics)
Genuine **SCD Type 2** dimension modeling on a proper star-schema retail dataset: MERGE-based logic handling all real-world change scenarios (new, changed, discontinued), a backfill-vs-recurring DABs job architecture with directly-verified idempotency, and a quantified proof table showing the exact dollar impact of skipping point-in-time history.
